# Code for 'Warming Drives Opposing Snow Accumulation Trends Across Elevations'

**Sarah Ryu, Stefano Casirati, Manuela Girotto**

Code repository for the analysis of historical elevation-dependent responses of snow water equivalent (SWE) accumulation to warming storms.

## Environment Setup

Create the project environment from [`environment.yaml`](environment.yaml):

```bash
conda env create -f environment.yaml
conda activate swe-elevation-warming
```
